OBS录制视频配置

OBS 录制视频的配置核心在于：用尽可能高的画质、尽可能低的系统占用，录制出流畅且便于后期剪辑的文件。

与直播（受限于网络带宽，只能用固定码率 CBR）不同，录制更推荐使用动态码率控制（如 CQP 或 CRF）。下面为你整理了一套针对不同需求的 OBS 最佳录制优化配置指南：

基础比该项（底层参数优化）

画布（基础）分辨率：设置为你显示器的原生分辨率（如 1920x1080 或 2560x1440）。
输出（缩放）分辨率：必须与画布分辨率保持一致。避免二次缩放，这样不仅画面最清晰，还能节省显卡资源。
# 常用帧率 (FPS)：
60 FPS：适合游戏录制、高速动感画面（首选，画面极度流畅）。
30 FPS：适合桌面演示、写代码、静态教学视频。

输出设置 - 录像（核心画质控制）

## 在「输出」中，将输出模式改为「先进（Advanced）」，然后切到「录像」选项卡。
1. 录像格式：推荐选择 mkv 或 fragmented_mp4 (分段 MP4)。
2. 避坑指南： 绝对不要直接录制成普通 mp4！一旦录制中途 OBS 崩溃、电脑断电或卡死，整段视频都会直接损坏报废。录制为 mkv，即使中断也能保留损坏前的内容，录完后在 OBS 菜单栏点击 文件 -> 重新封装录像，1秒钟就能无损转换成 mp4。
3. 音轨：根据需要勾选。如果想后期剪辑时将“系统声音”和“麦克风人声”分轨调节，建议勾选音轨 1 和 2（并在主界面的「高级音频属性」中做好通道划分）。



## 编码器与画质参数（针对不同硬件）
# 选项 A：NVIDIA 显卡（首选 Nvenc）
N卡拥有独立的硬件编码器，几乎不占用 CPU，录制游戏首选。
1. 视频编码器：NVIDIA NVENC H.264（如果是录制 4K 或是想节约空间，有 NVIDIA NVENC HEVC (H.265) 或是 AV1 更好）。
2. 速率控制：选择 CQP（恒定质量）。科普：CQP 模式下，画面复杂时码率自动飙高，静态时码率骤降，能用最小的体积换取最稳的画质。
3. CQ 水平（CQ Level）：18 - 23。
	1) 16 - 18：无损画质（剪辑、高要求游戏录制，文件较大）。
	2) 20 - 23：日常高清录制（性价最高，肉眼几乎看不出损失）。
	3) 注：数字越小画质越好，体积越大。不要低于 15，否则文件会极其臃肿。
4. 关键帧间隔：2 秒 或者是 0（自动）。
5. 预设（Preset）：P5 (慢速 / 优质) 或 P6 (较慢 / 更优质)。
6. 调谐（Tuning）：高质量（High Quality）。
7. 多通道模式：双通道（四分之一分辨率）。
8. 心理视觉调整（Psycho Visual Tuning）：勾选（能让动态画面更不容易马赛克）。

# 选项 B：AMD 显卡（AMF 编码器）
1. 视频编码器：AMD HW H.264 或 HEVC
2. 速率控制：选择 CQP。
3. I-帧 / P-帧 QP 值：设为 20 - 23。
4. 预设：Quality (质量)。

# 选项 C：核显/轻薄本或低配电脑（Intel QuickSync）
1. 视频编码器：Intel QuickSync H.264。
2. 速率控制：选择 LA-ICQ 或 ICQ。
3. ICQ 质量：设为 20 - 23。
4. 目标使用：balanced (平衡) 或 quality (质量)。

# 选项 D：无独立显卡 / CPU 极强（x264 软解）
如果你的电脑只有集成显卡，但 CPU 核心非常多，可以使用 CPU 压制。
1. 视频编码器：x264。
2. 速率控制：选择 CRF。
3. CRF 值：18 - 22。
4. CPU 预设：veryfast（最稳妥）或者 faster（如果 CPU 占用不超过 70%）。千万不要开到 slow 级别，CPU 会瞬间过载导致视频疯狂丢帧卡顿。

音频优化（告别沙哑与杂音）

一个优秀的视频，声音质量占了一半。
# 1. 音频设置【默认】
1. 进入设置里的「音频」选项卡。
2. 采样率：选择 48 kHz（画质音质对齐）。
3. 声道：立体声 (Stereo)。

# 2. 麦克风降噪（神级滤镜）
如果你的录制环境有风扇声、键盘声或电流麦，在主界面底部的 「音效混音器」 中找到你的麦克风，点击右侧的三个点 ... -> 选择 滤镜，依次添加以下滤镜：
1. 添加「杂讯抑制（Noise Suppression）」: 方法选择 RNNoise (使用较多 CPU，效果极好)。这可以干掉绝大多数背景环境音（如空调风扇声、键盘敲击声）。【过滤环境杂音】
2. 添加「限幅器（Limiter）」: 将 阈值（Threshold） 设置为 -2.0 dB 或 -3.0 dB。作用：无论你突然发出多大的声音或尖叫，麦克风声音永远不会超过上限，绝不爆音，保护观众耳朵。【防止声音爆音】
# 注意
「噪声抑制」在「限幅」的上方。
1. 这是最科学的顺序：先让 OBS 干净地除掉环境杂音，然后再把干净的人声音量进行限制。如果反过来，限幅器会把噪音一起放大，降噪效果就会大打折扣。

录像卡顿/丢帧排查清单

# 如果录出来的视频播放时一卡一卡的，或者 OBS 右下角提示“编码过载”：
1. 以管理员身份运行 OBS：右键 OBS 图标 -> 属性 -> 兼容性 -> 勾选“以管理员身份运行”。这能让 Windows 在游戏满载时，强行分出一部分GPU资源给 OBS，彻底解决因 GPU 抢占导致的录像卡顿。
2. 降低 CQP 质量：将 CQ 水平从 18 调大到 22 或 24。
3. 降低 Preset 预设：将 P6 调到 P5 或 P4。
4. 关闭 Windows「游戏模式」或「硬件加速 GPU 计划（HAGS）」：有时系统底层的调度冲突也会导致录制卡顿。

文件格式转换&进程优先级

### 文件格式转换
录制完 .mkv 视频后，别忘了在 OBS 主界面左上角点击 「文件」->「重新封装录像」，把录好的 mkv 导入进去，点击重新封装，1秒钟就能无损转换成剪辑软件（如剪映、PR、达芬奇）完美兼容的 mp4 格式！
## 1. 自动重新封装为 MP4（懒人神技）
在「高级」设置里，往下拉找到 「录像」 这一栏：
1. 强烈建议勾选：「自动重新封装为 mp4 (Automatically remux to mp4)」。
2. 爽点在哪里？ 勾选它后，你录制完点击“停止录制”的那一瞬间，OBS 会在后台静默、无损地帮你把 .mkv 自动转出一份同名的 .mp4 文件。你完全不需要手动去菜单栏转换了，录完直接就能拖进剪辑软件里用，极其省心！

### 进程优先级
1. 同样在「高级」设置最上方的 「常规」 栏：
2. 确认：「进程优先级」 是否已经设为 「高于正常 (Above Normal)」。这能防止电脑满载时录像出现卡顿。

核心录制源选择（解决“黑屏”与“性能”冲突）

显示器采集

# 录制对象
多个显示器
# 优化关键点
1. 适合需要频繁在多个软件、桌面、文件夹之间切换的场景。
2. 如果有多个显示器，新建多个“显示器采集”，在属性里分别指定对应的显示器。

窗口采集

# 录制对象
浏览器/VMware/Todesk远程桌面
# 浏览器优化关键点
必须关闭浏览器的“硬件加速”（详见下文），否则在 OBS 里极易显示为纯黑屏。
# VMware优化关键点
1. 抓取特定的虚拟机窗口。如果虚拟机内运行的是高帧率系统，建议在 VMware 设置中开启“加速 3D 图形”。
2. 如果画面卡顿，尝试在窗口采集的「采集方法」下拉菜单中，从“自动”切换为 “Windows 10 (1903及更高版本)”（这个独占采集模式性能极好且支持抓取 UWP 应用）。
# ToDesk优化关键点
远程画面本身会受网络影响产生图块，建议在 ToDesk 控制端将画质设为**“高清”或“超清”**，帧率设为 60 FPS，否则 OBS 录出来会显得很糊。
1. 在 ToDesk 的屏幕设置中，将传输模式改为“普通/游戏模式（高帧率优先）”，并手动锁定分辨率（最好与你本地显示器一致，比如 2K 或 1080P）。
2. 由于远程画面变化较大，之前设置的 CQP 18 在这里发挥了巨大作用。它会自动在远程画面剧烈闪烁或刷新时分配极高码率，确保远程文字录出来依然锐利清晰。

多光源场景的管理技巧

使用「分组」管理

# 在 OBS 的「源」列表中，按住 Ctrl 多选你刚才建立的采集源，右键选择 「分组选中项」。
1. 你可以建一个名为【工作流 A】的分组，里面放“显示器 1 + 浏览器”；建一个【虚拟机演示】的分组，放“VMware 窗口”。
2. 录制时，直接点击分组左侧的 “小眼睛”图标 即可一键显示/隐藏整套画面，避免画面穿帮。

利用「快捷键」一键切换（懒人必备）

# 进入「设置」 -> 「快捷键」：
1. 往下拉找到你创建的各个“窗口采集”或“显示器采集”.
2. 为它们的 “显示” 和 “隐藏” 设置快捷键（例如：按 F1 开启 VMware 画面，按 F2 隐藏并切换回主桌面）。这样在录像过程中，你无需切回 OBS 界面，盲操就能完美切换录制源。

其他

场景集合

如果你不想每次录制不同屏幕时都去右键调整，OBS 有一个神级功能叫 「场景集合 (Scene Collections)」。它可以帮你保存多套完全独立的分辨率、画布和源配置。
## 创建外接屏幕配置（比如 2K 屏）：
1. 在 OBS 顶部的菜单栏点击 「场景集合」 $\rightarrow$ 点击 「新建」 $\rightarrow$ 命名为 主屏幕_2K。
2. 进入 OBS 「设置」 $\rightarrow$ 「视频」，把分辨率设为你 2K 屏的 2560x1440。
3. 在左侧「源」里，添加你主屏幕的显示器采集，并调整好。
## 创建主屏幕配置（比如 2.5K 屏）：
1. 再次点击顶部菜单栏的 「场景集合」 $\rightarrow$ 点击 「新建」 $\rightarrow$ 命名为 副屏幕_1080P。
2. 进入 OBS 「设置」 $\rightarrow$ 「视频」，把分辨率设为副屏的 1920x1080（或者它对应的实际分辨率）。
3. 在左侧「源」里，添加副屏幕的显示器采集，并调整好。
## 场景集合使用
以后你想录制哪个屏幕，只需要在 OBS 顶部点击 「场景集合」，直接勾选 主屏幕_2K 或 副屏幕_1080P：
1. OBS 会瞬间自动把画布分辨率、视频参数、采集源全部切换到位。
2. 你不需要再手动去修改任何输出分辨率，也绝对不会发生画面错位、比例拉伸或黑边的问题，非常高效和优雅！


### 手动“使用此源的尺寸作为输出分辨率”的操作
## 右键应用源尺寸
在当前屏幕的采集源上右键，选择 「使用此源的尺寸作为输出分辨率」。此时，OBS 的输出画布会自动缩放到该屏幕的实际尺寸。
