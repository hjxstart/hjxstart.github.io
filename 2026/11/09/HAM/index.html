1. 135.7-137.8kHz频段属于低频(LF)，又称长波。
2. 1800-2000kHz频段属于中频(MF)，又称为中波。
3. 28-29.7MHz频段属于高频(HF)，又称短波。
4. 50-54MHz频段属于甚高频(VHF)，又称为米波
5. 2300-2450MHz频段属于特高频(UHF)，又称为分米波。WiFi的2.4GHz频段与此相邻。
6. 5.650-5.850GHz频段属于超高频(SHF)，又称厘米波。C波段卫星下行频率(3.7-4.2Ghz)与之相邻。
7. 10-10.5GHz频段属于超高频(SHF)，又称厘米波。Ku波段卫星下行频率(11.7-12.2Ghz)与之相邻。
8. 241-250GHz频段属于极高频(EHF)，又称毫米波。
9. THF一般指300Ghz以上。






# 212
业余电台与公众对讲机分属不同业务，频率和调制方式均不同，擅自 “扩频” 使用属违法操作，不能互相通信。
# 220
ITU 《无线电规则》将世界划分为3个区域 (region)，中国位于第3区。
# 221
全球3大区域的划分方法源自国际电信联盟 (ITU) 的 《无线电规则》
# 222
ITU 三大区域划分的概要描述: 1区 (欧洲、非洲、俄罗斯亚洲部分等), 2区(美洲), 3区(亚洲大部、大洋洲)。
# 223
在 ITU 第 3 区 (中国所在区)，40米业余波段的频率范围是 7.000-7.200MHz
# 224
对于 FM 模式 (带宽~20kHz)，为保证信号边带不超出规划范围。主载波需距频段边缘至少半个带宽 (10kHz)。
144.035 + 0.012 = 144.047MHz;
145.800 - 0.012 = 145.788MHz;
# 225
对于 SSB 模式 (带宽 ~3kHz)，主载波需距频段边缘至少半个带宽 (1.5 kHz)。
144.035 + 0.002 = 144.037MHz
145.800 - 0.005 = 145.795MHz (计算中考虑了频率容限)
# 228
29.3-29.51MHz是10米业余波段中划分给卫星业余业务 (Space Service) 的专用频段，其他业务不应占用。
# 229
145.8-146MHz是2米业余波段中划分给卫星业余业务的专用频段。
# 230
435-438MHz是70厘米业余波段中划分给卫星业余业务的主要频段。
# 231
“CQ分区” 是由美国 《CQ》 杂志制定的WAZ (Worked All zones) 奖状规则中定义的。
# 232
中国的 CQ 分区主要为 23、24、27分区
# 233
中国的 ITU 分区主要为 33、42、43、44、50分区

使用 ITU 标准的语音字母解释法 (如 Alpha, Bravo, Charlie等) 是国际通行的清晰拼读方法。

3DA0FZ/DL5CMP: 3=Three, D=Delta, A=Alfa, 0=Zero, F=Foxtrot, Z=Zulu, Portable=便携操作分隔符, D=Delta, L=Lima, 5=Five, C=Charlie, M=Mike, P=Papa

呼号(广为流传的另类字母解释法来拼读呼号) S53MNO: Sugar Five Three Mexico Norway Ontario
# 247
CQ 呼叫是普遍呼叫 (Call for Any station), 面向所有电台，部分国内国外。
# 248
标准呼叫格式: 重复 CQ 两到三次，报己方呼号两到三次，并说明 “呼叫CQ并等待” (calling CQ and standing by)
# 249
标准应答格式: 先报出对方呼号一次至两次，再报己方呼号一至两次，表示正在回应其呼号。
# 250
呼叫特定电台时应先呼对方呼号，再报己方呼号。建立联络后再说明具体事宜。
# 251
信号报告 (RST) 是业余无线电通联中首选交换的核心信息，用于相互确认通信质量和传播状况。
# 252
交换信号报告的首要目的是实时了解传播条件，以便双方选择最合适的频率、功率和天线进行操作。
# 253
RST 报告中，R(Readability) 代表信号可辨度，即信号清晰程度，从1 (无法辨识) 到 5 (非常清晰)
# 254
CW 报告用 RST 三位数 (559: 可辨度5, 强度5, 音调9); FM 报告用 RS 两位数 (55: 可辨度5, 强度5)。强度表指示为 S5, 故强度为 5。
# 255
在呼叫前询问 "Is this frequency in use?" (本频率有人使用吗？) 是国际通行的礼仪，可有效避免干扰他人正在进行的通信。
# 256
请求插入 (Break) 的正确方法是在对方通话间隙发出请求，得到许可后再加入，并报上自己的呼号。
# 257
遇险呼叫拥有最高优先级。听到遇险呼叫应立即停止所有发射，优先倾听并确认遇险情况，提供可能的帮助。
# 258
业余无线电礼仪的核心是尊重他人。请求插入前应考虑自己的加入是否会打扰原通信放的交谈。
# 259
对于不影响他人的飞快原则性操作问题，应通过私下方式友好地提出建议，避免在频率上公开指责。
# 260
对违法电台的干扰，个人不应在频率上与之对抗或进行压制，而应记录信息 (时间、频率、内容) 并向无委举报。
# 261
对于长时间的深入交流，使用电话或互联网等商用通信方式更为可靠、高效，且不占用宝贵的业余频谱资源。
# 262
电台日志必须包含的基本要素是: 日期、时间、频率、模式、对方呼号、双方信号报告。
# 263
用缩语表示日志必要内容即为: DATE, TIME, FREQ, MODE, CALL(对方), RST(双方)。
# 264
交换 QSL 卡片具有确认通联、设备验证、申请奖状、收藏纪念等多重意义。
# 265
一张有效的 QSL 卡片应包含双方呼号，通联时间、频率、模式、信号报告、操作员签名和通信地址等基本信息。
# 266
QSL 卡片是确认通联或收听 (SWL) 的证明，不应作为空白名片随意赠送。非通联获得的卡片应注明 "Eyeball QSO" 等
# 267
IRC (International Reply Coupon, 国际回信卷) 是对方为支付回邮邮资而附上的。收到后应确认日志，尽快直接回卡。
# 268
SASE (Self-Addressed Stamped Envelope) 即自带地址邮资的回邮信封，是请求对方回卡的常用方式。
# 269
SWL (Short Wave listener) 是指短波收听者，他们不发射，只收听并寄发收听报告卡。
# 270
144MHz (2米) 业余中继台大的标准频差是 0.6MHz (600kHz); 430Mhz(70厘米) 业余中继台的标准频差是 5MHz.
# 271
通过中继台呼叫某特定电台时，应直接呼叫对方呼号并报出己方呼号。
# 272
业余中继台是宝贵的公众资源，首要设计目标是保障应急通信，因此应尽量保持通信，避免长时间占用。
# 273
国际电信联盟 (ITU) 对 "深空" 的定义是指离地球距离大于等于 2 * 10^6 km的空间。
# 274
轨道倾角是指轨道平面与地区赤道平面的夹角，从赤道平面沿地球自传方向 (逆时针) 到轨道升交点的角度。
# 275
卫星的周期是指卫星连续两次经过升交点 (或轨道上其他固定点) 的时间间隔。
# 276
地球同步卫星的运行周期等于地球的自转周期 (23小时56分04秒)
# 277
太阳同步卫星的轨道平面与太阳和地球的连线始终保持一个固定的夹角，从而使卫星每次过顶某地的地方时大致相同。
# 278
地球静止卫星是位于地球赤道上空约 35786 公里、运行周期与地球自转周期相同、对地相对禁止的卫星。它是地球同步卫星的一种特殊类型。
# 279
升轨道 (Ascending Pass) 指卫星从南半球向北半球飞越的轨道段。
# 280
降轨道 (Descending) 指卫星从北半球向南半球飞越的轨道段。
# 281
卫星的周期是指它绕地球轨道运行一周所需的时间。
# 282
线性转发器将上行频率整体平移 (或反转) 一个固定频差后转发下来，不改变信号的调制特性，可同时中继多个信号。
# 283
线性转发器的核心特点是透明转发，保留输入信号的所有调制信息，支持SSB、CW、AM、FM等多种模式。
# 284 
卫星姿态变化 (翻滚) 会导致其天线极化方向相对于地面站发生变化，从而引起信号强度的周期性快哀落。
# 285
开普勒轨道看根数 (Keplerian Elements) 是描述卫星瞬间轨道状态的一组参数，是预测软件计算卫星位置的基础。
# 286
低轨卫星覆盖范围小，采用存储转发 (Store and Forward) 方式可实现全球通信，如APRS、SSTV、分组无线电等
# 287
最有效的方法是监听卫星的信标信号，调整上行功率使自己的下行型号强度与信标强度相近。
# 288 业余卫星通信中所说的A、B、K、JA、JD、S、T等工作方式，表示的是:
这些字母代号定义了转发器上下行频段和模式。例如: Mode A=2m上行/10m下行; modeB=70m上行/2m下行; Mode J=2m上行/70cm下行。
# 289
多普勒效应是指由于发射源与接收者之间的相对运动，导致接收频率发生偏移的物理现象。
# 290
多普勒频移规律是: 卫星飞来时相对速度增加，接收频率变高 (正频偏); 飞离时相对抗速度小，接收频率变低 （负频偏）; 距离越远，相对速度变化越快，频偏越大; 过顶时相对速度径向分量为零，频偏最小。
# 291
低轨道和椭圆轨道所需的发射能量较小，发射成本远低于地球同步轨道。
# 295
中文话音呼叫CQ的标准格式: 重复CQ三次，报己方呼号并用解释法拼读，再次说明 "呼叫CQ,听到请回答".
# 296
英文话音呼叫CQ的标准格式：CQ CQ CQ, this is [呼号] [拼读呼号], [呼号] calling CQ and standing by.
# 297
中文呼叫特定电台的标准格式: 重复对方呼号三次，报己方呼号并用解释法拼读，说明 "呼叫，听到请回答"。
# 298
英文呼叫特定电台的标准格式: [对方呼号] [对方呼号] [对方呼号], this is [己方呼号] [拼读己方呼号], [己方呼号] calling you and standing by.
# 299
中文报告信号的标准方式: 对方呼号，你的信号时xxx(报告值), 并询问对方是否超收(QSL?)。
# 300
英文报告信号的标准方式: 对方呼号: you are XXX(报告值), QSL?
# 301
QTH是Q简语，代表 "我的位置是..."
# 302
英文介绍位置: My QRH is [地点]
# 303
不通国家或地区的爱好者互致美好祝愿并表达再见之意的词:
Cheeiro(英式再见)、Ciao ciao(意式再见)、Do svidaniya(俄式再见)是不同国家爱好者在通联结束时的告别用语。
# 304
回应CW呼叫时，发报速度不应超过对方的速度，且必须保证自己能够准确抄收这个速度下的电码，以确保沟通顺畅。
# 305
QRL?是Q简语，意为 "这个频率有人使用吗?" "或你忙吗?" 用于呼叫前确认频率空闲。
# 306
业余电台 BH1ZZZ 用 CW 或其他文字方式发起CQ呼号的方法为: 
CQ CQ CQ DE BH1ZZSZ BH1ZZZ BH1ZZZ PSE K
CW呼叫CQ的标准格式: CQ CQ CQ DE[己方呼号] [己方呼号] [己方呼号] K (邀请任何电台回答)。
# 307 
业余电台 BH1ZZZ 使用 CW 或其他文字方式呼叫 BH8YYY 的方法为:
BH8YYY BH8YYY BH8YYY DE BH1ZZZZ BH1ZZZ BH1ZZZ PSE K
CW 呼叫特定电台的标准格式: [对方呼号] [对方呼号] [对方呼号] DE [己方呼号] [己方呼号] [己方呼号] K (要求该电台回答)
# 308
发送信号报告的标准格式: UR RST 579(您的RST报告是579) 或简化为 UR 579。
# 309
确认收到信号报告并致谢的标准格式: R(Roger, 收到) TKS(Thanks) FER(for) RPT(Report).
# 310
感谢对方进行良好通联的常用句: TNX FER NICE QSO(感谢这次良好的通联) ES HPE CU AGN(希望下次再见) 73 TU (致以最好的祝愿，谢谢你)
# 311
在竞赛或DX通联中，为追求速度，常用极简的 "TU" (Thank You) 来表达感谢和结束通联。
# 312
介绍自己的名字的标准格式: NAME [名字]
# 313
OP是Operrator (操作员)的缩语，介绍操作员名字: OP [名字]
# 314
DR是Dear (尊称的) 的缩语，用于礼貌地称呼对方操作员名字: DR [名字]
# 315
描述设备的常用缩语: RCVR/RX(接收机), XMTR/TX(发射机), XCVR/TXRX(收发信机), RIG(电台设备统称)
# 317
询问对方功率的最简单直接的方式: PWR? (功率?)
# 318
介绍功率约值的格式: PWR ABT [数值] w (功率约xx瓦). ABT=About
# 319
介绍天线的标准格式: ANT [天线类型] [高度] [单位]. GP=Ground Plane(垂直接地天线), MH=Meters High(米高)
# 320
交换天气信息的格式: WX [天气状况] ES TEMP ABT [温度] [单位]. WX=Wealther, ES=and, TEMP=Temperature, ABT=about.
# 321
进行CW联络，如需了解对方的抄手情况，除了 "QSL?"之外，我们还可以问 HW?
HW? (How Copy?) 是 "超收情况如何？"的常用缩语，用于询问对方是否听清或抄收。
# 323
QRM? 是询问 "我的信号有收到他台干扰吗?"
# 324
QRM 是告知对方 "你的信号正遭受他台干扰"。
# 325
QRN? 是询问 "我的信号有收到天电干扰吗？"
# 326
QRN 是告知对方 "你的信号正遭受天电干扰"。
# 327
CW 符号 "AS" (.--...) 表示 "等待 Stand By"。
# 328
"PSE QSL VIA BURO" 意为 "请通过卡片管理局 (Bureau) 寄送QSL卡片"。这里的QSL指实体确认卡片。
# 329
常用告别缩语: CU (See You), CU AGN (See You Again), GB (Good Bye)。
# 330
CW 符号 "SK" (...----.---) 通常表示通联结束 (End of Contact), 常与 "CL" (Closing) 同义。
# 331
QRP 操作时如果对方反映信号不好，我们可能会追问是否需要增加功率。此时可发送:
QRO? 是询问 "需要我增大功率吗？".
# 332
通联时，如认为 QRP 操作足以保证可靠联络，则可与对方协商降低功率。短句为:
QRP? 是询问 "(我) 可以降低功率 (进行QRP操作)吗？"。
# 333
QRP 是 Q 简语，表示 “请降低发射功率” 或 “我正在使用小功率发射”。在呼号后加/QRP通常表示操作功率不超过5W。
# 334
PSE QRQ 是 “请发得快一些” 的标准请求。
# 335
QRQ? 是 “(你是要求我) 发快一些吗？”， 用于确认对方的速度请求。
# 336
PSE QRS 是 “请发得慢一些” 得标准请求。
# 337
QRS? 是 “（你是要求我） 发慢一些吗？”，用于确认对方的速度请求。
# 338
QRT 是 Q 简语，表示 “停止发射”，常用于通联结束，表示要关机了。
# 339
QRU? 是询问 “你还有事吗？” 或 “你有消息要发吗？”，常用于通联结束前。
# 340
QRU 是告知对方 “我这里没事了” 或 “我没有消息要发了”。
# 341
QRV IN [活动名]？ 是 “你准备参加[某活动]吗？” 的常用句式。 QRV=Ready。
# 342
QRV 是 Q 简语，含义是 “我准备好了。”
# 343
QRZ? 是 “谁在呼叫我？” 或 “请重复你的呼号”，用于未听清对方呼号时请求重复。
# 344
QRZ 是 Q 简语，含义是 “你被XXX呼叫”，用于呼叫特定电台。做疑问句时意为 “谁在叫我？”

# 345
早期用 QSA 报告信号强度，分 1-5 级。现在信号报告中的 S(Strenght) 即源于此。
# 346
QSB? 是询问 “我的信号有衰落吗？”
# 347
QSB 是 Q 简语，含义是 “你的信号有衰落”，指信号强度发生波动。
# 348
QSD? 是询问 “我的发报手法有问题吗？”。 QSD=Keying defect.

# 350
QSD PSE CK 是告知对方 “发报有键击声，请检查 (你的电键)”。 CK=Check.
# 351
QSK 是 Q 简语，表示 “我可以在你发射的间隙中收听”， 即具备全断通 (Break-in) 功能，运行插入。
# 352
QSL? 是请求对方确认 “是否抄收?”。
# 353
QSL 是 Q 简语，含义是 “我承认收妥”，即确认抄收对方发送的消息。
# 354
QSO 是 Q 简语，含义是 “直接联络”，泛指业余电台之间的通信。
# 355
QSP [呼号]？ 是询问 “你能把消息转给[某某电台]吗？”。
# 356 
QSP 是 Q 简语，含义是 “我将为你转信至某台”。
# 356
QSX [频率]？ 是询问 “你正在[某频率]守听吗？”。
# 358
QSX [频率] 是告知对方 “我正在[某频率]守听”。
# 359
QSY [频率]? 是询问 “能否将频率改到[某某频率]？”。
# 360
QSY 是 Q 简语，含义是 “改变频率”。

# 361
QTH? 是询问 “你的位置 (地理位置) 在哪里？”。
# 362
"73" 是业余无线电中表示 “致以最美好的祝愿” 的传统缩语，用于通联结束。
# 363
"UR ADR?" 或 "UR ADDR?" 是询问 “你的地址是？”。 ADR/ADDR=Address。
# 364

# 365

# 366

# 367
"BOX" 或 "P O BOX" 是 "Post Office Box" (邮政信箱) 的常用缩语
# 368

# 369
CK 是 "Check" 的缩语，表示检查
# 370
CQ 是 "Calling any station" 的缩语，表示 “普遍呼叫”。
# 371
DX 是 "Distance" 或 "Distant" 的缩语，泛指 “远距离通信” 或 “国外电台”
# 372
ES 是 "And" 的缩语，表示 “和”。
# 373

# 374

# 375

# 376

# 380

# 382
GN 是 "Good Night" 的缩语，表示 “晚安”。

HNY 是 "Happy New Year" 的缩语，表示 “新年快乐”。

HPE 是 "Hope" 的缩语，表示 “希望”。 希望去做某件事
# 386
HPY 或 HPI 是 "Happy" 的缩语，表示 “幸福”、“快乐”
# 387
HST 是 "High Speed Telegraphy" 的缩语，表示 “快速收发报”
# 388
'K' 是 CW 中表示 “我已发送完毕，请任何电台回复” 的邀请符号。
# 389
缩语 'KN' 用于指示特定电台回复，常用于竞赛或拥挤频率，表示“请[某某电台]发射，其他电台保持守听”。

业余无线电通信缩语 "NW" 的意思是 “现在” (Now)。

'old man' 的缩语是 'OM', 用于友好地称呼对方操作员，无关年龄。

更正错误时表示 “抱歉” 的缩语是 "SRI" (Sorry)

# 413
CW 包的发射类别是 "A1A", 表示未调制载波的电报。
# 414
单边带话的发射类别是 "J3E"，表示抑制载波的单边带电话。
# 415
用 SSB 传输 SSTV 的发射类别是 "F3F", 表示调频传值。
# 416
调频话的发射类别是 "F3E"，表示调频电话。
# 417
用FM话传输 SSTV 的发射类别通用是 "F3F" (调频传真)
# 418
调频ATV (业余电视) 的发射类别是 "F3F" (调频传真)
# 419
带外发射调制产生的、刚超出必要带宽的发射 (杂散发射除外)，是需要控制的干扰。
# 420
AM、FM、PM的中文名称分别是幅度调制 (调幅)、频率调制 (调频)、相位调制 (调相)
# 421
FM 调制方式抗干扰能力强、音质好，被广泛应用于 VHF/UHF 本地通联。
# 422
SSB 调制方式带宽窄、功率利用率高，适用于 VHF/UHF 弱信号和远距离通信。
# 423
SSB 调制方式带宽窄、功率利用率高，是HF话音通信的主要方式。
# 424
与FM相比、SSB的主要有点是发射带宽窄，节省频谱
# 425
相比 SSB 方式，FM 的主要缺点是: 无法同时守听多个信号。
# 426
VHF/UHF 频率的SSB通联通常选用上边带 (USB)
# 427
14MHz 及以上HF频段的语言通信通常选用上边带 (USB)
# 428
7MHz 及以下HF频率的语音通信通常选用下边带 (LSB)
# 429
10.1MHZ 上下使用不同边带是业余无线电界长期形成的惯例，旨在统一标准，减少 confusion
# 430
发起SSB呼叫时，应与周边电台频率保持 2-3kHz 间隔，避免相互干扰。
# 431
单边带调制(SSB)是从调幅(AM)发展而来，属于调幅范畴(抑制载波调幅)
# 432
业余无线电中，CW特指等幅电报 (Continuous Wave), 即莫里斯电码通信
# 433
CW (等辐包) 只需极窄的带宽来传输信号，是所有调制方式中带宽最窄的。
# 434
FM 带宽远大于 CW 所需的最小带宽，不符合 "带宽最小化" 的无线电管理原则。
# 435
过强的音频输入会导致信号失真，产生不必要的谐波和互调，展宽发射带宽，降低通信质量。
# 436
'AM 调制中'，载波幅度随调制信号变化，'频率不变'(A); 已'调波振幅'与调制信号瞬时值'成正比'(B)
# 437
调幅型号可根据载波和边带抑制情况分为多种类型: AM、DSB-SC、SSB-SC、VSB，描述均正确
# 438
'USB 调制' 在频域上相当于将基带信号频谱 (幅度和频率关系) 线性 '平移' 至载频位置。
# 439
'LSB 调制' 在频域上相当于将基带信号频谱 '倒置后' 再线性平移至载频位置。
# 440
'FM 调制中'，载波频率随调制信号变化，'振幅不变'(A), '瞬时频偏(频率变化的幅度)'与调制信号瞬时值'成正比'(B)
# 441
FM 信号的频偏 (频率变化的幅度) 由调制信号的幅度决定。
# 442
'PM 调制中'， 载波相位随调制信号变化，'振幅不变'(A)；'瞬时相移'与调制信号瞬时'成正比'(B)
# 443
FM 信号带宽由调制信号的 '最高频率和最大频偏共同决定' (卡森公式)
# 444
SsB 信号带宽基本等于调制信号本身的带宽 (例如 语言带宽约2.7kHz)
# 445
WPM (Words Per Minute) 速度的一种计算方法是统计一分钟内的 “点” 数除以 '50'
# 446
WPM 速度的标准定义是以'单词' “PARIS” 为基准，一分钟能发多少个 “PARIS” 即为多少 WPM.
# 447
标准莫尔斯电码 timing 为: 点=1T, 划=3t, 点划间隔=1t, 字符间隔=3t, 词间隔=7t (t为点长) '13137'
# 448
波特率(B)与WPM的换算关系为: B(波特)=WPM/1.2 # '/'
# 449
常数 K 取决于信道条件: 衰落信道(如HF) 取'5', '非衰落'信道(如VHF FM) 取3
# 450
调频话必要带宽的估算公式为: Bn='2*(M+D)', 其中M为最高调制频率，D为峰值频偏
# 451
业余SSTV和FAX通常采用 'FM' 调制方式将视频音频信号调制到射频上。

SSTV 信号中的短促 "咯咯" 声是 '行同步信号'， 用于接收端同步扫描行起始。
